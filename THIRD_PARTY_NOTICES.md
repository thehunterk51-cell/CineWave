# Third-party notices

CineWave bundles one file that is not covered by the project
[MIT licence](LICENSE):

```
app/src/main/assets/adblock_hosts.txt
```

It is generated by [`tools/build_blocklist.py`](tools/build_blocklist.py) and is
also the file the app refreshes from
`raw.githubusercontent.com/thehunterk51-cell/CineWave/main/app/src/main/assets/adblock_hosts.txt`
so that a list update reaches devices without a new APK.

No third-party source code is bundled. Every line of Java, JavaScript and CSS
in this repository was written for this project.

## How this file complies with CC BY 3.0

Section 3.a of the licence asks that the Appropriate Legal Notices travel with
the work. They do:

| CC BY 3.0 requirement | Where it is satisfied |
| --- | --- |
| Identification of the creator | AdAway and contributors, named in the header of the file |
| Copyright notice | `Copyright (c) AdAway and contributors`, in the same header |
| Notice that the work is licensed under CC BY 3.0 | Stated in the header, with the licence link |
| Link to the material | <https://github.com/AdAway/adaway.github.io>, in the header |
| Indication of modification | The header states the file is a *modified* version |

The modifications are: the three sources are merged, each line is normalised to
the handful of formats this app parses, entries that fail validation are
dropped, and a curated project-owned set of ad and redirect domains is added.

Domain names are facts rather than copyrightable works, but the attribution is
reproduced in full regardless, because the source list is licensed CC BY 3.0.

The curated additions written for this project are covered by the project MIT
licence.
